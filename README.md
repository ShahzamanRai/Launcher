# OneScreen Launcher

A customized AOSP launcher built on top of **Launcher3**, tailored for OneScreen’s enterprise Android devices.

## Overview

This project includes two distinct versions of a launcher optimized for large-screen and interactive panel devices. Built using **Java**, **Kotlin**, and **Jetpack Compose**, the launcher is designed to deliver a clean, responsive, and user-friendly experience aligned with OneScreen’s product goals.

Key features:
- Custom layouts for both portrait and landscape modes
- Optimized grid system and app categorization for education and enterprise use
- Seamless performance on IFPDs and embedded devices

> ⚙️ This launcher was successfully deployed across commercial OneScreen devices and passed **Google EDLA certification**, meeting compliance and stability requirements.
